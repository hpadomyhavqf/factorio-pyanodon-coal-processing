## Overview

Pyanodon's Coal Processing integrates into the Pyanodons mod suite, adding detailed coking ovens, tar processing, and carbon-chain recipes that make coal the backbone of a rich chemistry industry.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Pyanodons Coal Processing** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Coking Ovens** | Multi-stage coke production from raw coal with byproduct capture |
| **Tar Processing** | Fractionate coal tar into light oils, pitch, and creosote |
| **Carbon Chemistry** | Extended recipe chains converting coal carbon into advanced materials |
| **Pyanodon Sync** | Full integration with Pyanodon Industries and Raw Ores item lists |
